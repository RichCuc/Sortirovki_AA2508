# Данные для гномьей сортировки Зыкова

В каждом файле 5000 одинаковых целых значений от -2500 до 2499, различается только порядок. Формат: числа через пробел, без количества элементов в начале. Подходят для чтения как int или double.

- `gnome_best.txt` — возрастающий порядок: лучший случай, O(n), обменов нет.
- `gnome_average.txt` — случайная перестановка (seed 42): пример среднего случая, ожидаемое время O(n²).
- `gnome_worst.txt` — убывающий порядок: худший случай, O(n²), 12 497 500 обменов.

Текущий main читает array.txt. Для проверки скопируйте нужный файл в array.txt и выберите пункт 2. Сохраните исходный array.txt перед заменой. При пакетном запуске передавайте каждому алгоритму исходный вектор из каждого файла.

Для сравнения времени используйте одинаковую сборку с -O2 и несколько прогонов. Вывод массивов не включайте в замер.
