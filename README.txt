Входные файлы для Sortirovki_AA2508

Всего 18 файлов с массивами и files.txt со списком их имён.
15 файлов best/average/worst содержат ПО 10000 ЧИСЕЛ.
Три отдельных файла размеров: size_100.txt (100), size_1000.txt (1000),
size_10000.txt (10000). Всего main делает 18 * 6 = 108 запусков.
Распакуйте содержимое архива в папку проекта. main менять не нужно.

Лучший/средний/неблагоприятный случаи сравниваем при ОДИНАКОВОМ размере.
Число элементов само по себе не определяет лучший или худший случай.
Случай зависит от порядка, значений, повторов и особенностей алгоритма.
Слова best/average/worst в именах являются обозначениями тестов.
Один случайный массив не является математическим средним по всем входам.
На одном замере время может не соответствовать ожидаемому порядку.

Расчёска:
best — возрастающий набор без обменов.
average — случайная перестановка того же набора.
worst — перестановка с наибольшим числом сравнений среди проверенных:
сравнили случайный average и ещё 64 перестановки/порядка.
Для выбранных данных comparisons: average 326734, worst 356731.
Абсолютный худший случай не доказан.

Гномья:
best — возрастающий набор, проход без обменов.
average — случайная перестановка того же набора.
worst — строго убывающий набор. Число соседних обменов максимально:
10000 * 9999 / 2 = 49995000.

Шейкерная:
best — возрастающий набор, обменов нет.
average — случайная перестановка того же набора.
worst — строго убывающий набор с максимальным числом обменов.
В текущем алгоритме нет раннего выхода при отсутствии обменов.
Число сравнений одинаково для этих трёх порядков, даже в best:
10000 * 9999 / 2 = 49995000. Число обменов различается.

Пирамидальная:
best — 10000 одинаковых чисел 0.250000, heapify не спускается вниз.
Повторы здесь намеренны. Это вырожденный случай для этой реализации.
average — случайный порядок различных чисел.
worst — наибольшее число сравнений среди average и 64 других кандидатов.
Comparisons: average 235290, worst 244460.
Абсолютный худший случай не доказан. Между различными перестановками
разница времени может быть небольшой и перекрываться шумом измерения.

Поразрядная:
best — целочисленные значения от 1.000000 до 9.000000.
После удаления нулей определяется scale=1, требуется один проход.
average — дроби с двумя знаками, до четырёх цифр после масштабирования.
worst — числа с шестью знаками, модули от 1 до 9.999999.
После масштабирования модули имеют семь цифр, нужно семь проходов.
Это неблагоприятный случай в выбранном диапазоне, не абсолютный худший.
На время также влияют строковые преобразования и распределение по знаку.
Используйте актуальную версию radixSort с llround.

Размерные файлы size_100, size_1000, size_10000 сохранены без изменений.
Все исходные массивы содержат только числа через пробел, без размера
или заголовков. Разделитель дробной части — точка.
Все значения подходят для текущей поразрядной без переполнения int.

Для сравнения выполните несколько прогонов и возьмите медиану.
Теоретическая сложность описывает рост числа операций, а не гарантирует
конкретное время каждого отдельного запуска на вашем компьютере.

Сборка: clang++ -std=c++17 -O2 *.cpp -o sorts
Запуск: ./sorts
